## About

This is my personal **Hyprland desktop setup** for Arch Linux.

It's built around a custom HUD, Waybar, notifications, audio controls, network controls, media controls, wallpapers, launchers, and a bunch of other desktop stuff.

I wanted everything to have the same general style instead of having every application look completely different.

---

## Features

### Custom HUD

The main part of the setup is a custom Waybar/HUD interface with things like:

* Workspaces
* Clock and date
* CPU and RAM information
* Network status
* Audio controls
* Bluetooth controls
* Media controls
* Notifications
* System information
* Quick settings

A lot of it is interactive too, so it's not just there to look nice.

### Audio

Quick access to volume, mute, audio devices, and media controls using the normal Linux audio stack.

### Network

Network status and controls are available directly from the HUD.

### Bluetooth

Bluetooth devices can be viewed and managed without needing to open a separate settings application.

### Media

Currently playing media can be displayed directly in the interface with basic playback controls.

### Notifications

A custom notification center that matches the rest of the desktop instead of looking like a completely separate application.

### Launcher

A simple monochrome application launcher designed to fit the rest of the setup.

---

## Desktop

I also use a few things directly on the desktop:

* Fastfetch
* Cava
* CMatrix
* TTY clock

They're set up to stay out of the way of normal windows, so they can sit on the desktop without covering whatever I'm actually doing.

---

## Customization

I'm also turning the setup into more than just a collection of config files.

The goal is to have one place where I can change things like:

* Colors
* Opacity
* Borders
* Corners
* Effects
* Wallpapers
* Keybinds
* Hyprland plugins
* Default applications
* Launchers
* Display settings
* Audio settings
* Network settings
* Lock screen
* Idle behavior

Basically, I want to be able to change the desktop without having to hunt through a million different config files.

---

## Style

The setup is mostly **black and white**, with dark glass/blur elements where they make sense.

```text
background    #000000
foreground    #ffffff

style         monochrome
theme         dark
```

I wanted it to stay pretty minimal while still having enough visual stuff to make the desktop interesting.

## Why

I wanted a desktop that actually felt like **mine**.

I like the Hyprland workflow, but I wanted to customize pretty much everything around it and have all the different parts match.

So I built the HUD, Waybar setup, notifications, controls, overlays, and other stuff around the same black-and-white style.

Basically, I just wanted my desktop to look good, work how I want, and feel consistent.

## Setup

This setup is currently made for **Arch Linux + Hyprland**.

```bash
git clone https://github.com/yummyfiles/<repo>.git
cd <repo>
```

Then follow the setup instructions in the repository.

Since this changes desktop configuration, it's worth looking through the files and scripts before running everything.
